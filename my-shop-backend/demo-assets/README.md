# Development catalog images

The demo seed copies these WebP files into ignored `storage/images/` using stable UUID filenames. No image download is needed when seeding. They are excluded from the production Docker image along with the private demo credentials.

The clothing images reuse this workspace's existing mobile product images and cached Unsplash images. Additional example images were downloaded from Unsplash and resized to WebP:

These are illustrative development fixtures; the seeded descriptions and customer/order history are fictional.
